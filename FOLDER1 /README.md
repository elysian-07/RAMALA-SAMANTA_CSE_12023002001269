# FOLDER1 — Selenium Web Automation Assignments

## 📌 Overview

This folder contains the Selenium Web Automation assignments completed as part of the Web Automation Lab.

The assignments focus on the fundamentals of Selenium WebDriver with Python, including web element identification, locating multiple elements, CSS selectors, and navigating child elements.

The folder also contains project reports and video demonstrations of the completed tasks.

## 🎯 Learning Objectives

Through these assignments, the following skills were developed:

1. Understanding Selenium WebDriver fundamentals.
2. Identifying web elements using different locator strategies.
3. Working with multiple web elements.
4. Using CSS selectors for element identification.
5. Understanding HTML parent-child relationships.
6. Automating interactions with web pages using Python.
7. Executing and troubleshooting Selenium scripts.
8. Documenting automation tasks and execution results.

---

## 📌 Conclusion

FOLDER1 demonstrates the foundational concepts of Selenium-based web automation using Python. The assignments provide practical experience in locating and interacting with web elements and form the foundation for developing more structured and maintainable Selenium automation frameworks.
